# Random Password Generator

## Description
A Python console-based Random Password Generator developed as part of the DecodeLabs Python Internship.

## Features
- Generate Random Password
- View Saved Passwords
- Delete Password
- Password Strength Checker
- Generate Multiple Passwords
- Save Passwords Automatically
- Load Passwords Automatically

## Technologies Used
- Python
- random
- string
- File Handling
- Functions
- Exception Handling

python password_generator.py
